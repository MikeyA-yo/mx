# RNNoise model

`sh.rnnn` is the "somnolent-hogwash" model from
https://github.com/GregorR/rnnoise-models (directory
`somnolent-hogwash-2018-09-01`), trained for speech with recording noise.
ffmpeg's `arnndn` filter loads it for the "strong" background noise
reduction.

That repository states that, apart from its tools, none of the work is
creative and none of it is subject to copyright.
